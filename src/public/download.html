ИНФОРМАЦИЯ

Как устроен Clop

Один сервис соединяет Telegram-бота, сайт, Windows, Linux, Android и iPhone.

01

Единый аккаунт

Вход через Telegram связывает устройства с одним тарифом, моделями и лимитами.

02

Общие модели

Доступность GPT и Kimi приходит с сервера и меняется без переустановки приложения.

03

Прозрачные действия

Clop Code показывает работу с файлами и сообщает точный путь каждого результата.

СБОР ИНФОРМАЦИИ

Какие данные используются

Понятный список без скрытых рекламных трекеров на этой странице.

ID

Для аккаунта

Нужно для общего входа и синхронизации.

  • Telegram ID, имя и username
  • Тариф и выбранная модель
  • Проценты использования и время сброса
AI

Для ответа ИИ

Передается только во время вашего запроса.

  • Текст сообщения и история диалога
  • Файлы и изображения, которые вы прикрепили
  • Результат, длительность и состояние запроса
✓

Чего здесь нет

Страница загрузки не запрашивает вход.

  • Пароли и коды Telegram
  • Банковские данные
  • Рекламные профили и продажа истории

Локальные данные Clop Code: рабочие папки, резервные копии и локальная история приложения остаются на вашем компьютере. Выбранный текст и файлы отправляются серверу только при выполнении запроса.

СКОРОСТЬ API

Единый серверный замер
