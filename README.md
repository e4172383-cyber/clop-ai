# Clop ai

Telegram-бот, веб-чат, личный API и desktop-клиент с единым аккаунтом через Telegram.
Проект работает на Node.js 22+ и поддерживает каталоги GPT и Kimi через настроенные CLI-провайдеры.

## Локальный запуск

1. Установите Node.js 22+ и авторизуйте нужные CLI-провайдеры.
2. Создайте локальный `.env` рядом с `index.js`.
3. Запустите `npm start`.

Минимальная конфигурация:

```dotenv
BOT_TOKEN=<telegram-bot-token>
WEB_PORT=8787
TOKEN_LIMITS_JSON=<private-plan-limit-matrix>
CORPORATE_LIMITS_JSON=<private-corporate-limit-matrix>
```

Режимы запуска:

- `node index.js --no-web` — только Telegram-бот;
- `node index.js --no-bot` — только веб-сервер;
- `npm run relay` — локальный CLI-ретранслятор.

## Конфиденциальные тарифные лимиты

Точные токен-квоты не хранятся в Git и не передаются в пользовательские интерфейсы. Сервер загружает готовую матрицу личных тарифов из обязательной переменной `TOKEN_LIMITS_JSON`, а общие командные пулы — из `CORPORATE_LIMITS_JSON`. В Render обе переменные объявлены с `sync: false`, а их значения задаются только в закрытых настройках сервиса.

Бот, сайт, desktop-клиент и личный API используют один серверный счётчик. Пользовательские и административные экраны получают процент использования, состояние исчерпания и время обновления окна без размера квоты. Фактический расход отдельных запросов может отображаться как метрика работы модели и не раскрывает размер тарифа.

Если закрытая матрица отсутствует, неполна или содержит недопустимые значения, процесс завершает запуск с ошибкой. Производственного значения по умолчанию в исходниках нет.

`/start`, `/new`, `/chats`, `/model`, `/usage`, `/plans`, `/corporate`, `/team`, `/team_add`, `/team_remove`, `/phone`, `/buy`, `/myapi`, `/balance`, `/download`, `/help`.

## Личный API и Telegram-боты

В разделе «Мой API» ключ создаётся в одном из двух режимов: общий лимит подписки или оплата по фактическому использованию. Баланс пополняется через Telegram Stars по курсу 86 звёзд за $1; одна операция пополнения — от $1 до $500. Списание выполняется после успешного ответа модели и использует отдельные цены для обычного входа, кэшированного входа, записи кэша и выхода.

Веб-конструктор создаёт размещаемого Telegram-бота по одному из четырёх шаблонов. Токен BotFather и ключ внешнего API шифруются и не возвращаются клиенту. Бот может работать с лимитом подписки Clop, балансом по факту или собственным OpenAI-совместимым API. Telegram Business Beta поддерживает черновики владельцу и автоответы от имени подключённого Business-аккаунта; набор доступных чатов владелец задаёт в настройках Telegram.

## Clop Code

Актуальная версия desktop-приложения: **2.2.0**. Загрузки для Windows x64 и Linux x64 опубликованы на странице `/download`; та же страница доступна из Telegram-бота. Точные размеры тарифных квот в репозитории и пользовательских интерфейсах не публикуются.

Исходники приложения находятся в `desktop/`:

- `npm ci` — установить зависимости;
- `npm test` — проверить политику доступа, ответы и файлы;
- `npm run dist` — собрать Windows x64 EXE;
- `npm run dist:linux` — собрать Linux x64 tar.xz.

## Данные

Пользователи, чаты, история, события использования и платежи сохраняются через слой хранилища проекта. Локальные секреты, данные и рабочие каталоги исключены из Git через `.gitignore`.

## Развёртывание на Render

`render.yaml` содержит только имена секретных переменных. Перед первым запуском задайте их значения в Environment сервиса, включая `BOT_TOKEN`, секреты сессий, параметры хранилища, `TOKEN_LIMITS_JSON` и `CORPORATE_LIMITS_JSON`.

Проверка процесса: `GET /health`.
